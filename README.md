# AQUABOT: Smart Agriculture Field Assistant

An autonomous robotic vehicle for precision agriculture.

## Hardware Stack
- Arduino Uno R3
- LEGO Technic Chassis
- 5-Channel Line Tracking Sensor Array
- Capacitive Soil Moisture Sensor & pH Sensor Module
- 12V Micro Submersible Water Pump

## Core Features
1. Autonomous Navigation: Uses line-tracking to follow ground paths.
2. Environmental Sensing: Halts at plants to read soil moisture and pH values.
3. Targeted Dispensing: Activates relay to dispense precise water doses.

## SDG Alignment
Aligns with SDG 2 (Zero Hunger) and SDG 6 (Clean Water).
